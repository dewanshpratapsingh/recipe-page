This is a static recipe page built as part of my React learning path. The project showcases:

✅ Component-based architecture using functional components

🎨 Scoped styling with CSS Modules

⚛️ Clean and modular React design

🚀 Deployed on Vercel for lightning-fast performance

The goal of this project was to get hands-on experience with React fundamentals—breaking down a UI into reusable components and applying scoped styles using CSS modules.

📁 This is a beginner-friendly project focused on code readability, reusability, and static rendering.
